1. 研究問題與要估計的效果（estimand）

以「模擬目標試驗」（target trial emulation）的架構描述：

要素 本研究
對象 臨床第 II–III 期、HER2 陽性乳癌，於收案期間在本院開始術前化療合併 trastuzumab，並在本院手術或手術前惡化
比較的治療策略 術前化療＋trastuzumab＋pertuzumab（雙標靶） vs 術前化療＋trastuzumab（單標靶）
指標日（時間零點） 第一筆術前抗癌藥醫囑日
治療分組 指標日起至手術前一日（或術前惡化日）之間，有任一筆 pertuzumab（含 Phesgo）醫囑 → 雙標靶；否則單標靶
結果 pCR（主要）、EFS（次要）、OS（探索性）
要估計的效果 重疊族群平均治療效果（ATO）：在「兩種治療都可能被選用」的病人中，雙標靶相較於單標靶的效果

選擇 ATO 的理由見 §5 與決定紀錄（2026-10-09）。

2. 研究族群

依 IRB 核准的納入與排除條件，由 analysis/R/cohort.R 依序篩選，並產生收案流程圖（results/figures/cohort_flow.pdf）：

  1. 癌登 HER2 陽性紀錄 → 去除完全重複的登錄
  2. 排除：診斷時遠端轉移、臨床第 0–I 期、HER2 非陽性（IHC 3+ 或 ISH 擴增以外）、診斷年齡 < 20 歲
  3. 排除：本院無抗癌藥醫囑、先手術後才用藥、術前治療不含「化療＋trastuzumab」、術前用 T-DM1、指標日不在收案期間
  4. 排除：本院無手術紀錄且無術前惡化（已查證為他院手術、無病理報告）

資料前處理：原始資料先比對 checksum，再套用資訊室更正檔，接著去識別化；處理方式見 analysis/data_queries.yaml。

已知無法套用的排除條件：「其他活動性惡性腫瘤」與「曾參與相關臨床試驗」，資料中沒有這些欄位，會在論文的研究限制中說明。

3. 結果變項

3.1 主要：病理完全反應（pCR）

  • 定義：ypT0/is ypN0，也就是乳房無侵襲性癌殘留（只剩原位癌也算），且腋下淋巴結完全沒有腫瘤細胞。 ypN0(i+)（孤立腫瘤細胞）與 ypN1mi 都不算 pCR（BIG-NABCG／ICCR 國際定義；決定紀錄 2026-10-09）。
  • 術前惡化、未手術者視為非 pCR。
  • 有手術但 yp 分期空白者：目前收案名單中沒有這種病人；若日後出現，主分析排除，並做「視為非 pCR」的敏感度分析。

3.2 次要：無事件存活（EFS）

  • 起算：指標日。
  • 事件：術前治療期間惡化致無法手術（以惡化日計）、局部或區域復發、遠端轉移、任何原因死亡，以先發生者為準。
  • 設限（censoring）：追蹤終點，取最後門診與最後一次醫囑中較晚的一天；死亡者取死亡日；不超過追蹤截止日。死亡後的醫囑視為預開未執行，不計入（資訊室查證 D4、D5）。
  • 與計畫書的差異：計畫書的 EFS 事件還包括「對側侵襲性乳癌」與「第二原發侵襲性惡性腫瘤」，但資訊室提供的資料沒有這兩個欄位，因此無法納入，會在研究限制中說明（決定紀錄 2026-10-09）。

3.3 探索性：整體存活（OS）

指標日至任何原因死亡；設限規則同 EFS。

4. 傾向分數模型

以邏輯斯迴歸估計「接受雙標靶」的機率，也就是傾向分數。共變項全部是治療前的特徵，事先指定如下：

類別 變項（編碼）
病人 診斷年齡（連續）、停經狀態、ECOG（0／1／2）、BMI（連續）、基期 LVEF（連續）
腫瘤 臨床 T（T1–T4）、臨床 N（N0–N3）、荷爾蒙受體（ER 或 PR ≥ 1%）、HER2（IHC 3+ vs IHC 2+／ISH 擴增）、組織學分級（1–3）、Ki-67（連續）
治療背景 術前化療組合（含 anthracycline vs 含 carboplatin）、指標日年份（連續）
  • 連續變項取線性項。化療組合和 pertuzumab 是同時決定的，屬於同一段治療處方，不是被 pertuzumab 影響的結果，所以當作共變項。
  • 不使用任何治療後才發生的變項，例如手術方式、術後治療。

5. 加權方法與平衡檢查

  • 主分析：重疊加權（overlap weighting）。雙標靶者的權重為 1 − 傾向分數，單標靶者為傾向分數。這種方法會自動把份量放在兩種治療都可能被選用的病人身上，不會出現極端權重。
  • 為何不用計畫書原訂的 IPTW：兩組的治療年代幾乎沒有重疊（早年幾乎只有單標靶，近年幾乎只有雙標靶）。設計階段的試算只用了基期資料、沒有看任何結果，顯示 IPTW 會讓少數病人得到極大權重：單標靶組的有效樣本數只剩約 5 人，且加權後仍不平衡。重疊加權則能讓所有共變項完全平衡，有效樣本數約為每組 70–90 人。
  • 平衡標準：加權後每個共變項的 |SMD| < 0.1。報告加權前後的 SMD（以 love plot 呈現）以及兩組的有效樣本數。
  • 檢定力的說明：加權後的有效樣本數遠小於全部人數。若真實的 pCR 差距與 NeoSphere 試驗相近（約 17 個百分點），檢定力約為 60%。因此結果以效應值與 95% 信賴區間為主，不以 p 值作為結論的唯一依據。

6. 統計分析

6.1 pCR（主要）

  • 加權邏輯斯迴歸（只放治療組），估計**勝算比（OR）**與 95% 信賴區間。這是計畫書原訂的效應指標。
  • 同時報告加權後兩組的 pCR 比例，以及**風險差（RD）**與 95% 信賴區間，方便臨床解讀。
  • 標準誤以 M-estimation 校正傾向分數估計的不確定性（WeightIt glm_weightit）。

6.2 EFS 與 OS

  • 加權 Kaplan-Meier 曲線；加權 Cox 模型估計風險比（HR）與 95% 信賴區間（穩健標準誤）。
  • 報告 3 年與 5 年的加權 EFS／OS 比例。
  • 用 Schoenfeld 殘差檢查比例風險假設；若明顯違反，改報 5 年限制平均存活時間（RMST）的差異。
  • 追蹤時間中位數以反向 Kaplan-Meier 法估計。

6.3 多重比較

只有一個主要終點，以雙尾 α = 0.05 判定。次要與探索性結果不做多重比較校正，以描述性方式解讀。

6.4 次族群分析（探索性）

依荷爾蒙受體狀態（陽性 vs 陰性）分組，比較 pCR 的效果，並檢定交互作用。結果只作為產生假說之用。

7. 缺值處理

  • 傾向分數共變項中有缺值的是：組織學分級、Ki-67、診斷年齡（1 人，生日為系統預設值）。
  • 以多重插補（mice，20 組，種子固定）補值。插補模型納入所有傾向分數共變項與治療組，不納入任何結果變項。
  • 每組補值資料各自估計傾向分數、權重與效應，再以 Rubin 法則合併。
  • 敏感度分析：完整個案分析（只用沒有缺值的病人）。
